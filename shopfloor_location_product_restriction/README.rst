This module allows to display an error to the operator as soon as
destination is filled in in scenarios if a location product restriction
is defined on the scanned destination location.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

When operators use scenarios that does not validate the movement at the
end of the flow, but allows to validate the picking later (e.g.:
receptions), the user won't have an error before.

Configuration
=============

See ``stock_location_product_restriction`` module.
