This module is a glue module that integrates the
**stock_release_channel** module with the **stock_picking_split**
module. It ensures that when a stock picking is split, the new picking
is linked to the same release channel as the original picking.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

When the user or the system split a stock picking, the system will
create a new stock picking. If this process occurs while the picking is
linked to a release channel, you expect the new picking to be linked to
the same release channel as the original picking.
